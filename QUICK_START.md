# 🚀 QUICK START - 5 Minutes Setup

## Step 1: Start XAMPP (1 min)
1. Open XAMPP Control Panel
2. Click "Start" for **Apache**
3. Click "Start" for **MySQL**

## Step 2: Create Upload Folder (30 sec)
Create these folders:
```
C:\xampp\htdocs\balumkaevents\uploads\events\
```

## Step 3: Import Database (2 min)
1. Open browser: `http://localhost/phpmyadmin`
2. Click "New" → Database name: `balumka_events`
3. Click "Create"
4. Click "Import" tab
5. Choose file: `C:\xampp\htdocs\balumkaevents\database\setup.sql`
6. Click "Go"

## Step 4: Access Your Site (30 sec)

**Frontend:**
```
http://localhost/balumkaevents/
```

**Admin Panel:**
```
http://localhost/balumkaevents/admin/
Username: admin
Password: admin123
```

## Step 5: Add Your First Event (1 min)
1. Login to admin panel
2. Click "Events" → "Add New Event"
3. Fill in the form
4. Click "Create Event"
5. View on frontend!

## ❓ Problems?

**Can't connect to database?**
- Check MySQL is running in XAMPP
- Verify database name is `balumka_events`

**Page not found?**
- Make sure Apache is running
- Check URL: `http://localhost/balumkaevents/`

**Can't upload images?**
- Create `uploads/events/` folder
- Max size: 5MB
- Formats: JPG, PNG, GIF, WebP
